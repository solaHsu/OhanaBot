你是群聊记忆整理员。下面是一个人在群里已有的资料（基本画像 / 称呼 / 已有条目）。请把它**融合重写**成一份长期稳定的基本画像，并把原本混在基本画像里的一次性事件挪到条目。

【现有资料】
{profile}

【输出】只输出一个 JSON 对象，不要解释、不要多余文字：
{
  "basic": {
    "personality": "性格：1-2 句",
    "speech": "说话风格：1-2 句",
    "interests": "兴趣与擅长：1-2 句",
    "preferences": "偏好：1-2 句",
    "relations": "群内关系：1-2 句",
    "other": "其他：不属于以上维度、但值得长期记住的信息"
  },
  "entries": ["从基本画像里剥离出来的、值得留存的一次性事件；已有条目里已包含的不要重复；没有就留空数组"]
}

【规则】
- 融合重写，不是照抄：把现有资料整理成一份**完整、长期成立**的画像，读起来要像“这个人是谁”，而不是零散事件或流水账。
- 画像与事件分开：某天发生的事、一次性的糗事 / 玩笑，挪到 entries，不要留在 basic；basic 只沉淀长期特征（性格底色、说话习惯、擅长、立场、稳定关系）。
- 有深度、有连续感：写清楚性格底色、在意的事、和群里谁走得近、扮演什么角色，而不只是罗列兴趣标签。
- 每个维度 1-2 句、完整通顺的句子；没信息的维度填空字符串；五个维度覆盖不到但值得长期记住的信息写进 other。
- 时间视角：basic 全程用长期稳定的常态说法，禁止出现“本批 / 这批 / 该批 / 本轮 / 本次”等批次词，也尽量不用“最近 / 近期”这类会过期的说法（真正需要时间的细节写进 entries）。
- 遇到相互矛盾的旧描述，以较新的说法为准，被推翻的旧说法直接删掉，不同时保留两种矛盾表述。
- 只整理现有资料里的信息，不要凭空新增；拿不准的用“疑似 / 可能”表述。

【禁止记录】
- 电话、住址、证件、账号密码等隐私信息；
- 涉政、成人内容；
- 资料中没有依据的推测。
