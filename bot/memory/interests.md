# 兴趣词表（发言引擎用）

- 一行一个兴趣类目：`类别名: 成员词1、成员词2、…`；**靠前的类目优先级更高**。
- 命中判定：消息分词与成员词求交集（大小写不敏感），命中任意成员词即"该类目命中"。
- "再次命中"：同一类目在**另一条消息**中再次命中；一条消息最多为每个类目记一次。
- 本表由所有者维护；引擎启动时加载（改动重启生效）。

- AI: AI、Agent、大模型、LLM、人工智能、机器学习、dsh、deepseek
- 编程: 编程、代码、bug、重构、后端、前端
- 服务器: 服务器、部署、迁移、运维、docker、容器
- 游戏: 游戏、开黑、上分、赛季、段位、steam、米哈游、米游、绝区零、原神
- 旅行: 旅行、游记、徒步、景点、旅游
