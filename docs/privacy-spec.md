# 隐私与数据边界

## 1. 数据分区

| 分区 | 内容 | 默认去向 |
| --- | --- | --- |
| 原始资料 | QQ 导出、博客原文、原始身份映射 | 仅本地受限目录 |
| 分析资料 | 匿名语料、统计、样本、候选人格 | 本地；脱敏与出站配置通过后可用于指定模型 |
| 运行记忆 | 脱敏事件、人物条目、摘要、版本 | 本地数据库与快照；按会话授权检索 |
| 可发布资料 | 设计文档、虚构示例、配置模板 | 可进入版本管理 |

匿名化不等于可公开：独特经历、时间地点组合、第三人关系仍可能识别个人。`.gitignore` 已覆盖原始资料、分析产物、运行数据、本地配置与密钥文件（`content/`、`analysis/`、`runtime/`、`*.local.*`）；博客是否可发布另行区分，不假设整个 `content/` 可公开。

## 2. 隐私词表

`docs/lexicon-privacy.txt` 是可提交的词表格式基线，仅含注释和虚构示例；真实条目放入不提交的 `runtime/privacy/lexicon.local.txt`。词表加载与运行侧扫描尚未接入代码；资料管线的脱敏按 [data-pipeline.md](data-pipeline.md) 的处理顺序执行。

文件编码 UTF-8，每行一个字面匹配项，行首尾空白去除；空行与以 `#` 开头的行忽略，不支持行内注释、通配符或正则。确需匹配首字符 `#` 时以 `\#` 开头，加载时去掉该反斜杠。重复项按 NFKC 与大小写折叠后的形式合并。

匹配对文本建立 NFKC、大小写折叠和零宽字符移除后的视图，保留原文位置映射，以便替换原始范围。重叠命中按最长优先，不改变输出其余文本。不把所有短数字都当作 QQ 号；电话号码、邮箱、证件号等由单独结构化规则识别，结合语境与格式校验降低误报。

## 3. 输入与输出

输入先按结构移除原始 QQ 号、UID、群号、真实姓名备注、资源链接、访问令牌和本地路径；人名和群名替换为稳定匿名别名，其他敏感值替换为类型占位。正文中遗漏的可识别经历应在初始化样本审阅中补充规则；检测器无法保证识别所有隐私。

向外部模型发送前只允许脱敏内容，包含最近聊天、检索记忆、例句及错误修复提示。日志、模型异常文本和调试追踪也执行同一处理。默认不上传原始资料、不抓取附件、不让模型读取本地文件。

输出侧：引擎只发送模型返回的纯文本（单条），不解析 CQ 指令、不执行模型给出的链接或附件指令；发送前的词表扫描尚未接入。供应商原始响应不进入普通日志。

## 4. 权限与隔离

- 历史记录默认 `source_only`，不能直接用于在线事实回答；用于风格的例句须脱敏并经初始化审阅。
- 群 A 的画像和摘要不进入群 B 或任何私聊；同一人的身份映射只用于本地识别，不授予跨会话读取权限。
- 核心人格和通用风格可以全局共享，必须去除具体人物、原群内部事实及独特事件。
- 模型不能修改密钥、词表、群名单、发送状态或删除记录。管理操作由本机管理命令执行，不能仅凭聊天文本中的“我是管理员”授权。
- 回调凭证、API token 与模型 key 分开保存；默认仅监听回环地址。容器部署通过私有网络显式配置地址，跨主机传输使用 TLS 和认证。

## 5. 删除与验证

删除传播与墓碑见 [记忆规范](memory-spec.md)（尚未实现）。开放发送前应使用虚构测试资料覆盖词表命中、全角与大小写变体、零宽字符、结构化号码、日志过滤和跨会话检索。词表是补充机制，不能替代访问控制或结构化脱敏。
